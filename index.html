Evidence

Evidence, not adjectives.

The Tracklint panel, recording a lab store. Every finding states its severity, its platform, the event it comes from and the check that raised it.

  1. 1Severity — errors, warnings and notes, counted.
  2. 2Plan status — every row: correct, failed, to review or not observed.
  3. 3Platform — each finding names the platform that sent it.
  4. 4Event — the captured request it comes from, by number.
  5. 5Origin — the automatic check or plan rule that raised it.

Principles

Four rules every product follows.

  1. 01

    Local analysis

    The extension and the local MCP server analyze on your computer. Tracklint does not send the tracking data it inspects elsewhere, and its MCP server tools open no network connections.

    An AI client may send the conversation, tool arguments and results to its provider; claude.ai chat runs no local MCP tools.

    SourceTracklint privacy policy
    tracklint-mcp README

  2. 02

    The minimum permission

    Tracklint requests only the storage permission. It does not request host permissions or the cookies permission.

    Sourcemanifest.json
    "permissions": ["storage"]

  3. 03

    Declared limits

    Tracklint checks captured browser requests. It does not verify processing inside Google, Meta or TikTok, server-to-server traffic, or legal compliance.

    Source“Privacy and limits”
    Tracklint website

  4. 04

    Two languages

    Tracklint’s interface, store listings, guides and exported reports are published in English and Spanish.

    Source_locales/en
    _locales/es
